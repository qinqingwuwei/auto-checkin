# 后续改进建议

本轮已覆盖 WebUI 登录 / 登出、操作取消、程序内定时、退出程序、旧后台任务清理、平台独立产物和 Tag 发布校验。

| 优先级 | 改进 | 当前情况与收益 |
| --- | --- | --- |
| 高 | 选择开源许可证 | **已完成**：采用 MIT 许可证，仓库根目录附 `LICENSE`。 |
| 高 | 真实账号验收与接口维护 | 现有测试使用模拟响应；产品私有接口易变，需要本人验收扫码、短信、换票、积分台账和失效重登录。 |
| 中 | 系统密钥库 | 当前凭据是 0600 本地 JSON；集成 macOS Keychain、Windows Credential Manager、Linux Secret Service 可改善静态凭据保护。 |
| 中 | Windows 签名与 macOS 公证 | 当前是标准 ZIP 裸二进制分发；平台签名可改善首次运行体验，需要项目签名证书与发布配置。 |
| 中 | 发布供应链记录 | 增加依赖清单、SBOM、产物证明和固定 Action 提交，便于公开版本追踪与验证。 |
| 低 | 更新提示与更多架构 | 可读取 GitHub 最新版本提示用户手动升级，按实际需求增加 Linux ARM64、Windows ARM64；需对应平台验收。 |

定时任务继续保持进程生命周期模式。若以后增加系统后台运行，须提供明确的独立开关、后台状态、退出提示和卸载入口，不能由安装脚本默认启用。
